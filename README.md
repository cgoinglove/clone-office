# sub-office

**Every computer is a sub-office.**

An AI office for a team. Each person's bots work on their own computer — their own browser,
sign-ins and keys, on the model they pick — and the office ties them together: shared skills,
documents and credentials, a reception desk, a CEO bot, and bots that can ask each other for work.

Status: design. Nothing to install yet.
